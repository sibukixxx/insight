# 公的統計スナップショット（デモ用）

Insight Lab のデモシナリオ `ja-official-population`（公的統計）と `ja-population-establishments`（公的統計＋架空メモ）の元データです。統計値はすべて `raw/` に保存した e-Stat 統計ダッシュボード API のレスポンスそのものから取っています。手で入力した数値はありません。

## 取得したもの

- 取得日: 2026-09-28（日本時間）。ファイルごとの正確な UTC 時刻は `raw/RETRIEVAL.json` を参照
- 提供元: e-Stat 統計ダッシュボード API（`https://dashboard.e-stat.go.jp/api/1.0/Json/`、登録不要）
- 地域: 茨城県 水戸市 `08201`、常陸太田市 `08212`、つくば市 `08220`（`getRegionInfo?ParentRegionCode=08000` で確認）

| raw ファイル | 内容 | 系列コード | 時点 | 単位 |
|---|---|---|---|---|
| `population_census_2015_2020.json` | 総人口（総数）／国勢調査（統計コード 00200521） | `0201010000000010000` | `2015CY00`, `2020CY00` | 人 |
| `establishments_private_2016.json` | 事業所数（民営）（～2016年）／経済センサス（00200552） | `0701010001000010010` | `2016CY00` | 事業所 |
| `establishments_private_2021.json` | 事業所数（民営）／経済センサス（注記「2021年は「経済センサス-活動調査」。」） | `0701010001000010012` | `2021CY00` | 事業所 |
| `regions_ibaraki.json` | 茨城県の市区町村の地域メタデータ | – | – | – |
| `statinfo_kokusei.json`, `statinfo_ecensus.json` | 調査メタデータ（作成機関: 総務省統計局） | – | – | – |
| `stat_*_gaiyo*.html` | 総務省統計局の調査概要ページ（調査期日の確認用。Shift_JIS のまま保存） | – | – | – |

使った値（raw からそのまま転記）:

| 地域 | 人口 2015 | 人口 2020 | 事業所数（民営）2016 | 事業所数（民営）2021 |
|---|---|---|---|---|
| 水戸市 | 270,783 | 270,685 | 13,136 | 12,442 |
| 常陸太田市 | 52,294 | 48,602 | 1,794 | 1,621 |
| つくば市 | 226,963 | 241,656 | 8,346 | 8,208 |

市区町村の「事業所数」合計系列（`0701010000000010000`）は2009年・2014年しかないため、2016年・2021年がある民営系列を使いました。統計ダッシュボードには2025年国勢調査の速報値も登録されていますが、確報ではないので取得範囲（`TimeTo=2020CY00`）から外しています。

## ライセンスと出典表記

- 統計ダッシュボードのコピーライトポリシー <https://dashboard.e-stat.go.jp/static/terms>: 「公共データ利用規約（第1.0版）」（PDL1.0）
- 参考: e-Stat 本体の利用規約 <https://www.e-stat.go.jp/terms-of-use> は政府標準利用規約（第2.0版）準拠で CC BY 4.0 と互換と書かれています。このデータの取得元は統計ダッシュボードなので、上の PDL1.0 が適用されます
- CSV に変換した時点で「編集・加工」にあたるため、次の3つをすべて表示します（`scenario.json` の `attribution`、各行末にも出典を記載）
  - 出典：統計ダッシュボード（https://dashboard.e-stat.go.jp/）
  - 統計ダッシュボード（https://dashboard.e-stat.go.jp/）のデータを加工して作成（Insight Lab デモ用に文章化）
  - このサービスは、統計ダッシュボードのAPI機能を使用していますが、サービスの内容は国によって保証されたものではありません。

## 生成と検証

```sh
node examples/demo-ja/official/build.mjs          # raw/ だけから CSV と scenario.json を生成（オフライン）
node examples/demo-ja/official/build.mjs --check  # raw の sha256 と生成物の一致を確認。差分があれば exit 1
```

出力先は `internal/sampledata/scenarios/ja-official-population/` と `internal/sampledata/scenarios/ja-population-establishments/` の `input.csv` と `scenario.json` です。

## 更新手順

1. `node examples/demo-ja/official/fetch.mjs`（ネットワークに接続。raw/ と RETRIEVAL.json を上書き）
2. `node examples/demo-ja/official/build.mjs`
3. `git diff` で値と文面の変化をレビューする

API レスポンスには取得時刻（`RESULT.date`）が入るので、値が同じでも取得し直すと raw の sha256、`retrievedAt`、CSV の取得日、`inputSha256` はすべて変わります。値の訂正や系列の変更が混ざっていないか、必ず差分を人が確認してください。統計局の概要ページの文言が変わると、build.mjs は調査期日の確認に失敗して止まります。

## 定義上の注意

- 国勢調査の総人口は、調査時点の常住人口です（平成27年・令和２年とも10月1日午前零時現在）。調査は5年ごとなので、2015年と2020年の間の各年の値はありません。増減の理由（転入・転出、出生・死亡）もこのデータには含まれません
- 市区町村の総人口には「日本人・外国人の別不詳及び年齢不詳を含む」（系列注記）
- 経済センサス‐活動調査の調査期日は平成28年6月1日（2016年）と令和3年6月1日（2021年）です。2021年の事業所数を2020年10月1日の人口と組み合わせても同じ時点の比率にはなりません（人口あたり事業所数などを作らない）
- 事業所の定義（統計ダッシュボード）は「経済活動が行われている場所」で、民営事業所は国及び地方公共団体の事業所を除きます。2016年と2021年の値は統計ダッシュボード上で別の系列として登録されており、2016年の系列注記は「社会・人口統計体系（SSDS）よりデータを登録している。」です。増減として比べる前に、対象範囲と定義が続いているかを確認してください
- 3つの地域コードは、getRegionInfo 上で2015年以前から現在まで同じコードのままです。ただし境界変更がなかったかどうかはこの取得範囲では確認していません
- `ja-population-establishments` の架空メモ3行（`memo-*`）は、実在の人物・企業・調査ではありません
